# chad-deploy-manifest.txt — Canonical source→destination map for Chad's
# pod. Read by scripts/chad-deploy.sh. Single source of truth so adding a
# new wrapper means adding one line here (not editing chad-setup.sh).
#
# Format (whitespace-separated; '#' for comments; blank lines ignored):
#   <src_rel_path>  <dst_path>  <mode>  <via>
#
# Fields:
#   src_rel_path  Path under the repo root (REPO_ROOT/<src_rel_path>).
#   dst_path      Absolute path inside the chad pod.
#   mode          chmod after install (octal, e.g. 755 / 644).
#   via           kubectl   → root-owned dest (/usr/local/**), kubectl exec.
#                 ssh       → sandbox-owned dest (/sandbox/**), plain ssh.
#
# Conventions:
#   • /usr/local/bin/        — chad-setup.sh-managed system tools. Root.
#   • /usr/local/share/chad/ — read-only data files (registry, profiles, paths). Root.
#   • /sandbox/.openclaw-data/bin/ — sandbox-writable tools (chad-webui,
#                                    chad-experiment, chad-shim runtime patch).
#                                    Chad can self-edit these.
#
# Adding a new entry: pick the correct dst convention above, set mode to
# 755 for executables / 644 for data. Run `chad-deploy.sh --verify` to
# confirm md5 matches; `--push` to install.
#
